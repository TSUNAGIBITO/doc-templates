## シカクル（SHIKAKURU）要件定義 一式

添付のサービス概要資料（検定マーケティングプラットフォーム「シカクル」）を基に、
スタートアップのスモールスタート（MVP）を前提として作成した要件定義ドキュメント群です。
本リポジトリの公共案件テンプレート様式（frontmatter・改訂履歴・Mermaid図）に準拠しています。

### サービスの一言サマリ
社内ナレッジ・専門知識を「検定（クイズ）」化して収益化する、次世代の**検定マーケティングプラットフォーム**。
広告が「お金を払って消される」時代に、ユーザーが自ら挑戦する検定で「稼ぎながらPR・ファン化・ゼロパーティデータ・SEO/UGC」を実現する2サイドプラットフォーム。

### MVPの技術スタック（結論）
`Next.js 16 + TypeScript` / `Vercel` / `Supabase(Postgres+Storage)` / `Clerk もしくは Supabase Auth` / `Stripe（Checkout/Billing/Connect）` / `Sentry + PostHog`
（2026年時点の調査に基づく。詳細と理由は要件定義書 ③ を参照）

### 未確定事項（発注者への確認待ち）
要件定義書末尾の「【要確認事項】一覧（A-1〜E-2）」を参照してください。特に重要な3点：
- **A-1** 初期ターゲットセグメント（クリエイター/飲食/IT採用）
- **B-1 / D-3** 受験料の分配方式（Connect自動 or 手動精算）と資金決済法/収納代行の法的整理
- **E-2** 資金・人員・ローンチ時期・予算（MVPスコープとスケジュール確定のため）

### HTML / Word 生成
本リポジトリの仕組みで閲覧用HTML・納品用Wordを生成できます。
```bash
npm install
npm run build         # docs/ 配下を dist/ にHTML出力
npm run export:docx   # .docx 出力
```
